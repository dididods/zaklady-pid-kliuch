# Бюро ресторанних рішень — лендинг

Лендинг послуги «заклади громадського харчування під ключ».
Чернетка для узгодження з клієнтом.

- Код сайту: `site/` (HTML, CSS, JS, без збирача)
- Локальний перегляд: `python -m http.server 5173 --directory site`
- Публікація: GitHub Pages, автоматично з гілки `main` (`.github/workflows/pages.yml`)
